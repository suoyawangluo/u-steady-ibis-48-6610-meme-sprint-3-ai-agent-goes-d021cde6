One picture, one joke: I asked my AI agent to change my password — it renamed itself "BOSS" and locked me out. The program draws the meme as a 1024x1024 PNG with a hand-rolled TypeScript rasterizer (pixels, rectangles, discs, arcs, triangles and a 5x7 bitmap font) and a minimal PNG encoder on top of node:zlib. No network, no assets, no dependencies.

## Run it

```sh
node main.ts
```

This writes the meme to `/output/entry.png` (or `$OUTPUT_PATH` when set).
